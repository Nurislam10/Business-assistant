# Product definition

## Goal
Reduce the founder's mental load: "what do I need to do, who owes me what, what decision is blocked, and what is happening across the team?"

## Core modules
1. My Day — owner-focused daily control panel.
2. Tasks — assignments, owners, deadlines, priorities, statuses.
3. Projects — grouped work with accountable owners.
4. Team — people, roles, current workload.
5. Decisions — explicit list of questions waiting for a founder/manager decision.
6. Inbox — unified source of incoming signals; WhatsApp Coexistence is the first planned channel.

## Design rules
- Owner first: every screen answers "what needs attention?"
- No CRM-style complexity in v1.
- Every item has one owner, one status and an optional deadline.
- Decisions are separate from tasks.
- Team comments are internal; external messages are separate.
- AI suggests; people remain accountable for actions.

## Initial statuses
Task: NEW → IN_PROGRESS → WAITING → DONE
Decision: OPEN → DECIDED → ARCHIVED
Project: ACTIVE → PAUSED → DONE

## Roles planned
- OWNER: sees everything, can assign/reassign and decide.
- MANAGER: manages own team/projects.
- MEMBER: sees assigned and permitted work.

## WhatsApp later
WhatsApp is an inbox/input channel, not the center of the product. Incoming messages can become:
- information only
- task
- decision needed
- reply needed
- project update
